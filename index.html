🚀 What is HTML?

Detail Informasi HTML

HTML stands for HyperText Markup Language. It is the standard markup language for creating Web pages.

Key Points:

  • Standard markup language
  • Describes the structure of a Web page
  • Consists of a series of elements

How HTML works:

HTML elements tell the browser how to display the content.

    🏷️ HTML Attributes

    Atribut HTML

    Attributes provide additional information about elements:

    Common Attributes:

    • href Specifies the URL for a link
    • src Specifies the path to an image
    • alt Specifies alternate text for an image
    • class Specifies class names for elements
    • id Specifies unique id for an element
    • style Specifies inline CSS styles
